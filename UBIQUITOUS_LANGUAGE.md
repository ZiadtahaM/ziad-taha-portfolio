# Ubiquitous Language: Developer Authority Hub & 81-Site Showcase Router

## Domain Concepts

### PortfolioSite
An immutable entity representing one of the 81 live Cloudflare Pages deployments built by Ziad Taha. Contains domain cluster classification, live deployment URL, verified local source code path, and architectural capability tier.

### DomainCluster
One of the 8 operational domains into which the 81 portfolio sites are partitioned:
1. B2B Agency, Lead Gen & Proposal Ops
2. EdTech, Arabic Academies & AI Learning
3. Healthcare, Clinic EHR & Service Booking
4. Internal B2B SaaS, Dev & Security Utilities
5. Creator, Headless CMS & Media Automation
6. E-Commerce, Multi-Vendor Marketplaces & PropTech
7. 3D WebGL, Interactive Maps & Toy Apps
8. Developer Authority Hub & System Orchestration

### ProductionLever
An automated verification script (`verify-*.mjs`) that exercises the domain's business contracts, financial conservation rules, and multi-lane verification gates.

### AuthorityDossier
The complete proof package returned to technical due-diligence reviewers, aggregating live daemon probe statuses, registered sites catalog, and verification levers.
